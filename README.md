# 📊 Excel Profit Dashboard on Sales

## 📌 Overview
This project is an interactive Excel dashboard created to analyze sales, revenue, and profit performance across 
multiple regions, products, and sales channels.

The dashboard helps in identifying:
- Yearly profit trends
- Revenue and profit by product category
- Online vs Offline sales performance
- Country-wise profit distribution
- Regional sales insights

---

## 🚀 Features
- Interactive slicers for filtering data
- Dynamic pivot charts
- Profit analysis by year
- Revenue vs Profit comparison
- Sales channel analysis
- Geographic profit visualization using maps
- Region and country-based insights

---

## 📊 Dashboard Insights
### 1. Revenue and Profit by Items
Compares total revenue and profit across different product categories such as:
- Clothing
- Electronics
- Food
- Furniture

### 2. Profit by Year
Shows yearly profit trends to identify high and low performing years.

### 3. Sales Channel Analysis
Analyzes profit generated through:
- Online Sales
- Offline Sales

### 4. Profit by Countries
Displays geographical distribution of profit using map visualization.
